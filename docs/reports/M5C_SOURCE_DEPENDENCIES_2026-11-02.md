# M5C source child-commit inventory

November 2, 2026. The local push preview now lists gitlinks from the exact proposed source commit. This is a bounded prerequisite for dependency review, not remote reachability proof or push authority. No push implementation, automatic authentication, child fetch, child checkout access or remote URL inference was added. Ordinary writes stay disabled. The separate M5B SecurityAgent operator acceptance gap remains open.

## Implementation

`PushPreview.source_gitlinks` contains raw byte paths and exact typed object IDs. The existing isolated read session runs `git ls-tree -r -z --full-tree` against the captured source OID. Git does not recurse into gitlink child worktrees or require their target commits locally. The reader preserves tab/newline/non-UTF-8 paths and validates the returned commit type/OID. It refuses more than 1,024 gitlinks rather than returning a partial list. The existing session timeout/cancellation, 2 MiB output bound, generation/configuration checks and final transport-context revalidation still apply. No `.gitmodules` content is treated as network authority.

The desktop preview renders the paths through the existing byte-safe display utility. It states that child checkouts and remote availability were not inspected and that separate intended-child-remote reachability proof, including outgoing-history requirements, is still necessary. There are no execution controls or implicit child selections. The response contract is regenerated; previews are ephemeral and no stored state migration is needed.
