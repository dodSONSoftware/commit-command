## Diagnosis and change

The [preceding crash checkpoint](G02_G06_RUNNING_PUSH_CHECK_CRASH_2026-11-07.md) recorded a blank first valid restart and recovery on a second launch. The retained fixture and original binary reproduced an empty native window on an ordinary launch; it subsequently populated without a relaunch. A further exact-host SIGKILL and first restart also recovered the saved draft. This isolates a reproducible startup exposure rather than establishing corrupt operation state or a permanently stuck renderer. The baseline record was committed as `a89ecc6`.

The host built its main webview hidden, restored geometry, then called `show()` immediately during setup. WebKit loads the bundled document asynchronously, so the user could see an empty surface before any document was ready. The host now requests its **initial display only after the first Finished page-load event**. A per-window atomic guard consumes that initial display once: subsequent navigation/renderer recovery still invalidates the old presentation and closes stale reviews, but does not invoke initial display again or deliberately unhide a hidden window. Display failures remain observable on stderr. The bundled HTML also contains a readable `Starting Commit Command…` status inside the root while React mounts.

Opt-in fixture audit now records main page Started/Finished events, visibility and elapsed time, plus the initial-display result. These records add no IPC, approval path, arbitrary script or renderer-supplied fault. Ordinary write defaults and existing caller/origin/approval checks are unchanged. No dependency changed.

This patch addresses the verified premature-display cause. The earlier prolonged blank was not reproduced as a distinct permanent WebKit failure, and this report does not assert a diagnosis of every possible renderer failure. Native AX discovery can briefly return native controls before exposing web content; completed content was verified separately rather than treating that initial inventory as proof of a stuck page. No arbitrary startup delay, automatic hook retry or journal rewriting was added.
